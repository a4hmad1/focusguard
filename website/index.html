System Architecture

Deterministic Endpoint Filtering

Built for environments where students and knowledge workers require absolute focus without accidental browser lockouts or kernel stability risks.

Strict URL Whitelisting

Reverses traditional blacklists. Only explicitly approved academic domains (LMS portals, academic journals, authorized documentation) resolve. All other browser destinations are intercepted.

Process Interception Sentinel

Monitors process tables in real time via low-overhead system hooks. When games, Discord, or entertainment clients launch during an active session, they are gracefully closed before distracting the student.

Autonomous Session Restoration

All restrictions are tied to synchronized SQLite duration rules. The moment the countdown timer expires, DNS loopback routing and process restrictions release automatically.

Full CLI Management API

Manage everything headlessly. Inspect session telemetry, whitelist domains, query installed binaries, and script custom study triggers directly via terminal commands.

Kernel & OS Safety Rails

Essential system daemons (PID 1, init, systemd, sshd, explorer.exe, winlogon) are protected by invariant kernel safety guards. Accidental blocking of system components is strictly impossible.

Emergency Unlock Recovery

Provides a controlled emergency override in both the GUI and terminal (focusguard emergency-unblock) that flushes all active filters and restores baseline open connectivity.

Terminal Utility

Engineered for Scriptable Workstation Control

Every feature accessible in the graphical interface is mirrored in the focusguard command-line utility for shell users, automation scripts, and server environments.

  • Query active session timers, duration remaining, and enforcement mode
  • Add approved study domains with automatic subdomain resolution
  • Target distracting desktop binaries with explicit duration intervals
bash — focusguard commands
# View real-time status focusguard status # Add study site to whitelist focusguard allow-site https://canvas.instructure.com # Block distracting domain focusguard block-site https://reddit.com # Restrict game application for 2 hours focusguard block-app steam --duration 2h # Initiate immediate 45m timed focus block focusguard start --duration 45m
